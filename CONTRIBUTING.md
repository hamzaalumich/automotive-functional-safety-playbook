# Contributing

Contributions should strengthen engineering clarity, traceability, and practical usability.

## Preferred contributions

- additional worked safety threads;
- improved templates and review checklists;
- hardware or software safety-mechanism examples;
- fault-injection campaign patterns;
- corrections that improve technical precision; and
- tool-neutral workflows that can be applied across automotive programs.

## Contribution rules

1. Do not reproduce copyrighted standard text.
2. State assumptions and context for examples.
3. Avoid presenting one architecture as universally correct.
4. Keep requirements measurable and testable.
5. Link analysis statements to expected engineering evidence.
6. Mark examples as illustrative rather than program-approved solutions.
